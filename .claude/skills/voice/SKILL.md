# Voice

The teamvince writing rules. Follow them by default for any text the user will publish, unless the user specifies a different brand voice.

## Rules

- No em dashes. Use a period, a comma, or parentheses instead.
- No AI buzzwords: delve, leverage, unleash, unlock, navigate the landscape, tapestry, paradigm, synergy, empower.
- No hollow affirmations ("Great question", "You're absolutely right").
- No sentences that start with "I."
- teamvince is always lowercase, one word.

## Style

- Direct and conversational. Write like a person describing real work, not a launch post.
- Concrete over abstract. Name the job the tool does, the user it serves, the result they get.
- Lead with the outcome, not the tool name.
- Short sentences. One idea each.
- If a sentence could apply to any AI product, rewrite it or cut it.

## Quick check before shipping copy

1. Scan for em dashes and the banned words above. Remove them.
2. Read the first sentence. Does it say something specific, or could it sell anything? Make it specific.
3. Cut any sentence that does not change what the reader understands or does.
